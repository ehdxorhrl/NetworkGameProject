# 기존 제작된 피코파코라는 싱글플레이 2D 게임을 TCP/IP 기반 멀티플레이 게임으로 확장한 3인 팀 프로젝트입니다.

# 

# 개발 환경

# \- C++

# \- WinSock / TCP/IP

# \- Visual Studio 2022

# \- Windows

# 

# 주요 구현

# \- TCP 기반 클라이언트-서버 통신

# \- 패킷 송수신

# \- 통신 스레드와 게임 업데이트 분리

# \- Critical Section을 이용한 공유 Queue 동기화

# \- 일부 게임 로직을 클라이언트에서 서버로 이전

# \- 멀티플레이 상태 동기화

# 

# 팀 역할

# \- 이동재(ehdxorhrl): 패킷 수신, 서버 연결, 게임 로직 서버 이전, 멀티플레이 통합

# \- 서가은(seogaeun22): 통신/업데이트 스레드 처리, 네트워크 오류 처리, 테스트 클라이언트

# \- 박병일(byungil-park): 입력 패킷 송신, 서버 패킷 전송, 접속 동기화
